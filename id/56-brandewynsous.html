Resep 40

Saus Brendi

Saus mentega hangat dengan brendi untuk puding

Untuk 8 porsi ✦ 15 menit

Bahan

  • 125 g mentega
  • 250 ml gula cokelat
  • 250 ml krim kental
  • 60 ml brendi
  • 5 ml esens vanili
  • Sejumput garam

Cara Membuat

  1. Lelehkan mentega dan gula bersama di atas api kecil sambil diaduk hingga gula larut.
  2. Tuang krim dan masak dengan api kecil selama 5 menit hingga agak kental.
  3. Angkat dari api dan aduk brendi, vanili, dan garam.
  4. Sajikan hangat di atas puding panggang, panekuk, atau es krim.

Tips dari Nico

Tambahkan brendi setelah diangkat dari api agar aromanya terjaga.
